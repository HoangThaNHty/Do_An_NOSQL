# Tài nguyên bên thứ ba

Giấy phép source project theo `LICENSE` được giữ từ repo GitHub của nhóm. Tài nguyên dưới đây có nguồn/giấy phép riêng.

| Thành phần | Bản đóng gói | Giấy phép / đối chiếu |
|---|---|---|
| Bootstrap | 5.3.3 | MIT, [bản kèm source](../static/vendor/bootstrap/LICENSE), [upstream](https://github.com/twbs/bootstrap/tree/v5.3.3) |
| Bootstrap Icons/font | 1.11.3 | MIT, [bản kèm source](../static/vendor/bootstrap-icons/LICENSE), [upstream](https://github.com/twbs/icons/tree/v1.11.3) |
| Be Vietnam Pro | File WOFF2 cục bộ | SIL Open Font License 1.1, [OFL.txt](../static/fonts/OFL.txt), [upstream](https://github.com/google/fonts/tree/main/ofl/bevietnampro) |
| Ảnh bài mẫu | JPEG cục bộ | Nguồn, tác giả, giấy phép từng ảnh tại [CREDITS.md](../static/images/CREDITS.md), dữ liệu máy đọc tại `static/images/credits.json` |

Giữ tên tác giả và giấy phép tương ứng khi dùng lại ảnh; không quy ảnh CC hoặc font OFL về MIT của project. Không cần tải lại tài nguyên để khởi động website.
